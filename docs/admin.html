Everything here edits docs/catalog.json. Publishing commits that file, and Android TV, Android mobile and Windows read it on their next launch — no APK, installer or portable copy is rebuilt. Order in this table is the order in the apps. Hiding a channel keeps the row; deleting it writes a tombstone, and switching that row back on clears the tombstone again. The # column reorders in place — type a number and the rest renumber. ClearKey DASH channels need their key id and key here, which is also how a new MPD link is added.
