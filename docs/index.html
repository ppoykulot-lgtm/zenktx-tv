Features

Built around a remote, not a mouse.

Every screen is reachable with the D-pad. The guide view keeps the channel grid, the filter chips and the detail strip on one screen, so browsing 485 channels never feels like scrolling a website.

📺

Made for Android TV

Leanback launcher, 320×180 banner, focus ring that follows the D-pad on NVIDIA Shield, Chromecast with Google TV, Xiaomi Stick and Android TV 7.0+.

⚡

Channel up / down while watching

CH+ and CH- hop through the list you were browsing — favourites, Pinoy or a single category — without going back to the guide.

🩺

No more silent black screens

A stall watchdog notices when a stream never produced video and shows the real reason: HTTP 403, geo-block, codec or timeout — with Retry and Next.

★

Favourites you can star

Long-press any channel to add it to Favourites. A dedicated chip filters the grid, and the star stays visible on the tile.

🖼

Fix your own logos

Streams without artwork can be given a logo URL, or the empty box can be removed — per channel, saved on the device.

🔗

Playlists + GitHub sync

Add any M3U/M3U8 or ZENKTX JSON URL, toggle sources on and off, and pull or push the whole list through a GitHub repository.

🔄

Updates that arrive by themselves

The app checks GitHub Releases on launch. A newer APK is downloaded inside the app and handed to the system installer.

🔐

Signed, tamper-evident builds

Release APKs are signed with a pinned certificate; a repackaged copy is detected and refuses to run.

🇵🇭

Pinoy channels up front

128 local channels are detected automatically and get their own filter chip, next to News, Sports, Movies, Kids and the rest.

Installation guide

Installed in under a minute.

Sideloading is normal for TV apps. Nothing here needs a cable if you use a downloader app.

1

Allow unknown sources

On the TV: Settings → Apps → Security & restrictions → Install unknown apps and allow your browser or file manager.

2

Get the APK onto the TV

Open the download link on the device itself, or use a downloader app such as Downloader by AFTVnews and paste the release URL.

3

Install

Open the downloaded file and confirm. ZENKTX appears in the apps row with its banner, right next to your streaming apps.

4

Optional: ADB

From a computer on the same network: adb connect <tv-ip>:5555 then adb install ZENKTX-TV.apk.

1

Download the APK

Tap the Mobile download button on this page. Chrome may warn that the file type can harm your device — it is the standard APK warning.

2

Allow installing

When prompted, allow Install unknown apps for Chrome or your file manager.

3

Uninstall the old copy first

Settings → Apps → ZENKTX → Uninstall. Android silently refuses a new APK on top of a copy signed with an older key, and the only message you get is App not installed. Your channels are not stored on the device, so nothing is lost.

4

Open and confirm

Tap Install anyway when Play Protect shows “Harmful app blocked” — that is the reputation warning for every sideloaded IPTV app. Tapping Got it cancels the install, which ends as App not installed. If the same message returns, free some storage and try from the file manager instead of the browser.

1

Download the installer

Two files ship together: ZENKTX-Setup-<version>.exe installs it properly, ZENKTX-Portable-<version>.exe runs straight from any folder. Take the installer unless you want nothing added to the system.

2

Pass SmartScreen

Windows may say the publisher is unverified: More info → Run anyway. There is no publisher certificate yet, so this warning is expected on both files.

3

Pick your channels

The guide opens with the bundled list. Use Ctrl+F to search, ↑ ↓ to move and Enter to play.

Common questions

Answers before you ask.

The warnings you will meet on a sideloaded app, and what each one actually means.

Why does Windows say the publisher is unverified?

The executables are not signed with a paid publisher certificate yet, so SmartScreen shows an unrecognised-app warning. Choose More info → Run anyway. The APKs are a different case: they are signed, and the app verifies that signature on every update.

Android blocks the install — what do I allow?

Android requires per-app permission to install files. On a phone, allow Install unknown apps for Chrome or your file manager when prompted. On a TV, open Settings → Apps → Security & restrictions → Install unknown apps and allow your browser or downloader.

Why is there no Play Store or Microsoft Store listing?

Both stores restrict apps that play third-party stream lists. ZENKTX ships as a direct download instead, which also means no store account and no store cut.

How do updates arrive?

The app checks GitHub Releases on launch and can download a newer APK itself, then hands it to the system installer. On Windows the app downloads the new build itself when you press the update button and reopens on it; a portable copy stays portable. Updates only arrive when the build for your platform actually changed.

How many channels, and where do they come from?

The bundled list carries 485 channels, and 128 Philippine channels are detected automatically so they get their own filter chip. You can also point the app at any M3U or ZENKTX JSON playlist of your own.

Do I need an account or a subscription?

No sign-in, no subscription. All settings, favourites and logos are stored on your own device; the only network calls are for the playlists and for update checks.

Version history & changelogs

What changed, release by release.

The five newest releases, each with what it changed. Everything older lives on the releases page.

1.5.4 latest

8 November 2026 · Android TV · Android mobile and Windows unchanged
  • The categories are one row again, without a label. Wrapped, the band grew a second line that sat flush under the first with no gap and pushed the guide down the screen. It is a single line that slides sideways now, with the chip at the edge fading out instead of being sliced in half, and the BROWSE caption is gone.
  • The logos take the card. A 50dp mark inside a 100dp cell still read as a stamp from the sofa. The cell is 128dp and the artwork 84dp — the tile is now mostly logo, with the name under it.
  • The search bar is centred under the categories instead of hanging off the left edge.
  • The player bar is one row. It stacked a time row above a button row, so the running time and the duration were painted over the volume and the pause button. Play first, then the elapsed time, the timeline, where the stream ends, the sound and the quality — one line, in the order a remote walks it.
  • Each release has its own card on this page. The five entries were nested inside the newest one's article, so every version inherited its padding and ran into the block above it. They are separate cards now, and the older releases are off the page entirely — the releases page still has them.

1.5.3

7 November 2026 · Android TV · Android mobile · Windows unchanged on 1.5.1
  • The TV guide is rebuilt around the remote. The categories are a labelled band that wraps instead of scroll-jumping under the highlight, the search bar sits under them and says Search channel, and the six-column grid of 84dp cells became five columns of 100dp cards with 50dp logos — on a 65” screen the artwork was the smallest thing on it.
  • A highlighted tile no longer disappears under the categories. Every cell lifted 6dp and scaled by 6% on focus, straight into the clip at the top of the grid, so its top edge and sometimes its name were cut. The grid now keeps the room for that lift, the chips row no longer scrolls itself when it takes focus, and the bottom of the guide is a legend of the D-pad keys instead of the detail strip.
  • Channel hopping is one press. The CH ▲ / CH ▼ pair, the favourite star and the ✕ over the picture are gone. On the picture, ▲ ▼ ◀ ▶ change channel and the banner names the new one — CH 214 / 465 — without raising the control bar over the picture, which is what made zapping feel messy. OK raises the bar, BACK lowers it, and a second BACK leaves the player.
  • The splash gets out of the way. The welcome screen held the guide back for a full ten seconds after the catalogue had already arrived, and a slow read kept it on screen even longer while it said Loading channels…. It now has a floor and a ceiling — it clears after 1.2s at the earliest and never later than 2.5s, with the grid filling in behind it — and the first tile takes focus as it lifts, so OK plays straight away.
  • Logos stay where they are. Artwork was cached for only as long as the host's ten-minute header allowed, and a request that timed out during the burst on launch was dropped until the tile was rebound — the same channel had a logo one launch and none the next. Logos now live in a 96 MB disk cache that ignores that header, and a failed request is retried twice before the cell stays empty.

1.5.2

7 November 2026 · Android mobile · Android TV · Windows unchanged on 1.5.1
  • Every channel name fits. An 84dp logo and two lines of name needed more room than the 118dp card gave them, so names like “Cartoonito Stream 2” were painted past the card edge and cut in half. The card is 132dp now and both lines sit inside it.
  • Search sits under the categories. The magnifier in the header opened a dialog, hid the results behind the keyboard and asked for a second tap before anything was found. On a phone the field is now a bar under the chips: type and the guide filters while you type, with the count, a clear button and the ✕ to empty it.
  • The detail sheet is gone from the phone. It took the bottom of the grid to repeat a name the tile already showed. A tap plays, and a long press on a tile adds or removes the favourite, so the star it held is still one gesture away.
  • Smaller buttons over the picture. The favourite star and the close ✕ in the phone player were 46dp, sized for a TV across the room. They are 38dp on a phone; the TV keeps its larger pair.

1.5.1

7 November 2026 · Android TV · Android mobile · Windows
  • The highlight follows the mouse. On Windows the guide only moved its outline after a click, so the strip at the bottom answered to the last tile you pressed instead of the one under the pointer. Resting the cursor on a tile selects it now, and a click still opens the channel straight away.
  • Tonight's NBA games appear. A game row is named “8:00am Wizards vs Hawks”, so nothing in the name says NBA — only its tags do. The guide tested the name alone and threw away every game the publisher added, which is why the other players listed a full night of basketball and this one listed none. It reads the tags now, on all three builds, so a game stream shows up within a minute of being published and leaves again when it is pulled.
  • Playlists is dark. The dialog had no background of its own and fell back to the browser's white sheet, which lit up the whole window. It uses the same surface, edge and radius as the rest of the app.

1.5.0

6 November 2026 · Android TV · Android mobile · Windows
  • One click starts a channel on every build. On Windows a tile used to select first and wait for a double click, which read as a guide that would not play; a single click now opens the player, and the phone follows the same rule. The phone grid is three across with larger logos instead of two rows of postage stamps, it runs without a status or navigation bar, and the header has a search button that filters the whole catalogue.
  • The player has a real control bar. The star, the volume wheel, the running time, a quality switch with Auto and a close button — the same row the Windows build has — replacing the bare LIVE badge. Close is the ✕ in the corner, and Esc closes it from a keyboard.
  • Channels are re-checked every ten minutes. Every launch already pulled a fresh list; a session left open now re-reads the catalogue and the publisher's feed on a timer, so a link that dies while you are watching is replaced instead of failing for ever.
  • Playlists can be fixed. A source saved with the wrong stream URL or logo is edited in place, and the truncated “menu” rows are gone: no GitHub sync, no hidden-channel list, no logo edits, and no right-click sheet on the tiles.
  • Logos appear on their own. The initials that stood in for every channel while its logo loaded are gone, so a guide of 450 tiles no longer paints and repaints itself.
